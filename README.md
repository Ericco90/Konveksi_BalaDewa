## Preview Website

![Preview Website](preview.png)

## Deskripsi

Website landing page untuk jasa konveksi pembuatan kaos, hoodie, dan seragam custom.  
Website ini dibuat untuk membantu bisnis konveksi memiliki identitas online dan memudahkan pelanggan melakukan pemesanan.

## Fitur Website

- Landing page bisnis
- Galeri produk
- Testimoni pelanggan
- Google Maps lokasi usaha
- Tombol WhatsApp pemesanan

## Teknologi yang digunakan

- HTML
- Tailwind CSS
- JavaScript
- GitHub Pages
